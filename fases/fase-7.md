FASE 7: Despliegue en la Nube y Dominio Propio (Publicación)
* Tarea 7.1: Subir y configurar la base de datos PostgreSQL en un proveedor cloud (Render, Supabase o Railway).
* Tarea 7.2: Desplegar el servicio Backend en la nube con sus variables de entorno de producción.
* Tarea 7.3: Desplegar el Frontend Web (Vercel o Netlify).
* Tarea 7.4: Comprar un dominio web propio (ej. destino3.com o .co) en Namecheap o GoDaddy.
* Tarea 7.5: Configurar registros DNS, certificados SSL (HTTPS) y conectar el dominio con la plataforma.
